# AR Mini Museum Assignment

We built a mini AR museum for our group project using the Hiro marker. 

## What We Made
We set up a pedestal base, an info sign, and some text floating over the marker. The main feature is a 3D fox statue sitting right in the center. 

We added two animations. The fox spins around in place, and a sphere next to it moves up and down.

For interactions, we kept the color-changing ball from class. Tap it and it changes color. We also wrote a quick component for the fox. Tapping it makes it grow or shrink. 

At the top of the page, there's a status bar. It turns green when the camera tracks the marker and red when it loses it.

## Built With
- A-Frame 1.3.0
- AR.js
- HTML & JS
